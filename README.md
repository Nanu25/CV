# CV Site

Welcome to my CV Site repository! This project is a personal website designed to showcase my journey in computer science, my achievements, and my projects. The site features a dynamic portfolio, a personal journal, and responsive design to ensure a seamless experience across all devices.

🖥 **Live Demo:** [Visit My CV Website](https://agportfolio-a13e2a8e20e4.herokuapp.com/)  

## Features
- **Responsive Design:** Optimized for desktops, tablets, and mobile devices.
- **Dynamic Content:** Easily update your journal, achievements, and project sections.
- **Modern Styling:** Clean and professional UI with gradient text, flexbox layouts, and custom animations.
- **Personalized Sections:** Includes an "About Me" section, portfolio, achievements, and a personal journal.

## Technologies Used
- **Django:** Python-based web framework for rapid development.
- **HTML & CSS:** Markup and styling for a modern, responsive design.
- **JavaScript:** Enhancements for interactivity (if applicable).
