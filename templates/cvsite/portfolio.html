This project is a Connect Four game that I built using Python during my first year of university. It implements the Minimax algorithm with Alpha-Beta pruning, allowing the computer to play strategically against the user. The game features a graphical user interface (GUI) built with Pygame, making it interactive and visually appealing. This project helped me explore AI decision-making and optimization techniques in game development.
